### OutputPanel 重构（三通道）
- `QComboBox` 放在面板标题行右侧（`[ OUTPUT ] ... [Clangd Log ▾] [Clear]`），
  下面挂 `QStackedWidget`，三页各持自己的缓冲：
  - `ChannelServer = 0` Clangd Log → `QPlainTextEdit`（serverLog_）
  - `ChannelBuild  = 1` Build Log  → `QPlainTextEdit`（buildLog_）——**默认显示**（stack 与 combo 都是 1）
  - `ChannelProblems = 2` Problems → `QTreeWidget`（2 列：Problem / Location）
- API：`appendServerLog()` / `appendBuildOutput()` / `setProblems()` / `showChannel()` / `clearOutput()`。
  **旧的 `appendOutput()` 已删除**，调用点按语义分流：clangd 生命周期与诊断计数 → server log；
  打开/保存/重载/编译器输出 → build log。
- 下拉项 Problems 的文本带实时计数（`Problems (1 error(s), 2 warning(s))`），
  这样在别的通道也能看到有错。空列表时列表里放一行不可选的 “No problems detected.”。
- combo 的 `currentIndexChanged(int)` **不能用 PMF 直接接 `showChannel(Channel)`**
  （int → 非作用域枚举 不是隐式转换，Qt 的 AreArgumentsCompatible 会编译失败），
  必须用 lambda 转换：`[this](int i){ showChannel(static_cast<Channel>(i)); }`。
- Clear 按钮清空**当前通道**；在 Problems 页时等价于 `setProblems({})`。

### Problems 列表跳转
- 行内数据角色：`Qt::UserRole` = 路径，`+1` = 行(0 基)，`+2` = 列(0 基)；
  按文件分组（父行 = 文件名，子行 = `severity: message [code]` + `Ln x, Col y`），`itemClicked` 单击跳转。
  父行 path 非空 → 跳到该文件第 0 行。
- `OutputPanel::problemActivated(filePath, line, column)` → `MainWindow::onProblemActivated()`：
  **先在所有 tab 里按 `lintPath()` 匹配**（未保存缓冲的诊断路径是虚拟临时路径，不能从磁盘重开），
  匹配不到才 `openFileInTab()`，然后 `CodeEditor::gotoLocation(line, col)`（居中 + setFocus）。
- `CodeEditor` 新增：
  - `normalizedDiagnostics()`：把零宽诊断归一化后的列表（保证列表行号与波浪线一致）。
  - `setDiagnostics()` 现在会 emit `diagnosticsChanged(lintPath(), normalizedDiagnostics())`。
  - `gotoLocation(int line, int column)`：0 基，`qBound` 到 block 长度内。
- `MainWindow` 保存 `QHash<QString, QList<LspDiagnostic>> diagnosticsByFile_`（键 = lintPath），
  `rebuildProblems()` 展平并按 `(filePath, line, column)` 排序后交给面板（QHash 迭代无序，
  不排序列表会跳来跳去）。关闭 tab / 保存导致 lintPath 变化 / 关闭 clangd 时同步清理或换键。

## 顺带修掉一个既有真 bug：数字高亮正则一直是无效的
- `CppSyntaxHighlighter` 的数字规则 `\b(...)?)|(...)|...)\b` 多了一个 `)`，
  Qt 报 `unmatched closing parenthesis` → 整条规则被 QSyntaxHighlighter 静默跳过，
  数字从来没被高亮过，而且每次重绘都往 stderr 刷 "called on an invalid QRegularExpression object"。
- 修复 = 把 alternation 收进外层 `\b(...)\b` 组（删掉一个括号）。用最小 Qt 程序验证：
  旧串 invalid / 新串 valid，且能匹配 42、0xFF、0b1010、1.5e3、10u、1'000，不误匹配标识符。

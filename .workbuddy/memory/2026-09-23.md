## 侧边栏 / 底部面板改为布局内 Widget（不再是可独立拖出的窗体）
用户诉求：底部面板与侧边栏要和编辑区同一套布局，不能拖出成独立浮动窗体。

- `FileExplorer`：`QDockWidget` → `QWidget`，内部 `QVBoxLayout`(标题行 + QTreeView)，
  标题行是加粗小字号 `QLabel("EXPLORER")`（顶替原 dock 标题栏）。
- `OutputPanel`：`QDockWidget` → `QWidget`，内部 `QVBoxLayout`(标题行 + QPlainTextEdit)，
  标题行 `QLabel("OUTPUT")` + 右侧 `QToolButton("Clear")`（autoRaise，连 clearOutput()）。
- `MainWindow`：删掉 `addDockWidget()`；改成嵌套 splitter 作为 centralWidget：
  - `mainSplitter`(Horizontal) = [fileExplorer_, tabWidget_]，stretch 0/1，sizes {260,1020}
  - `outerSplitter`(Vertical) = [mainSplitter, outputPanel_]，sizes {600,190}
  - 两个 splitter `setChildrenCollapsible(false)`：面板不能被拖到零尺寸。
  - 约束：fileExplorer_ minWidth 160，outputPanel_ minHeight 80（原 dock 的 max 限制去掉）。
- `MainWindow` View 菜单：`toggleViewAction()` 不可用，改为自建 checkable QAction
  `actToggleExplorer_`(Ctrl+B) / `actToggleOutput_`(Ctrl+J)，toggled(bool) 直接接
  `QWidget::setVisible`。splitter 会记住被隐藏面板的尺寸，重新显示时自动恢复。
- 验证：cmake 构建通过；ctest 67/67 通过；dist/lightcpp.exe 启动存活 4s 无崩溃。
